# Iris Species Classification

## Objective
Build a simple machine-learning model to classify Iris flowers into species.

## Files
- `iris.csv` - flower measurements
- `iris_classifier.py` - Decision Tree classification program
- `README.md` - documentation

## Method
1. Load the Iris dataset.
2. Separate features and target.
3. Split data into training and testing sets.
4. Train a Decision Tree classifier.
5. Calculate accuracy.
6. Predict a sample flower.

## How to Run
```bash
pip install pandas scikit-learn
python iris_classifier.py
```

## Expected Output
The program prints the model accuracy and the predicted species for a sample flower.
